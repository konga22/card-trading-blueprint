# Images

`public/images/` stores static assets used by the marketing routes and future catalog views.

Recommended folders:
- `cards/` for mock card thumbnails or placeholders
- `icons/` for product-specific SVG assets that are not covered by `lucide-react`
- `illustrations/` for empty, loading, or onboarding artwork

Naming rules:
- Use lowercase kebab-case filenames.
- Keep source files optimized before committing.
- Prefer SVG for icons and lightweight decorative assets.
- Do not mix temporary screenshots with production assets.
