# Card Trading Blueprint Master Design System

## Core Identity

- 톤: KREAM에 가까운 리셀 거래 서비스
- 인상: 흰 배경, 검은 CTA, 정돈된 가격 위계
- 금지: AI SaaS 보라색, 유리판, 팬페이지 분위기

## Visual Rules

- 전체 배경은 흰색
- 카드 구분은 선보다 면 차이와 여백으로 만든다
- 검정이 가장 중요한 색이다
- 신뢰 정보만 파랑/초록을 제한적으로 사용한다

## Layout Rules

- 검색창이 첫 CTA다
- 홈 첫 화면에서 검색, 대표 카드, 가격, 신뢰 기준이 모두 읽혀야 한다
- 시세는 차트보다 표/리스트 우선

## Image Rules

- 포켓몬 이미지는 공식 사이트 출처만 사용
- 비포켓몬은 억지 이미지보다 텍스트형 플레이스홀더 사용

## Anti-Patterns

- 선이 많은 레이아웃
- 장식적인 카드 테두리
- 과한 컬러 포인트
- 배경 장식이 전면에 나오는 랜딩
