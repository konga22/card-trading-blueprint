# Card Trading Blueprint Master Design System

## Core Identity

- 톤: 거래 서비스, 리셀 플랫폼, 검색 중심
- 인상: 단정함, 빠른 탐색, 신뢰 가능한 가격 정보
- 금지: AI SaaS 보라색 톤, 유리판, 과한 장식

## Reference Mix

- 번개장터: 검색 우선, 카테고리 진입, 거래형 홈
- KREAM: 가격 위계, 검수/정책 정보, 블랙 중심의 정돈감
- 당근: 안심 톤, 인간적인 카피, 낮은 진입 장벽

## Visual Rules

- 배경은 웜 뉴트럴 계열
- CTA는 블랙
- 강조는 오렌지 하나
- 신뢰 정보는 블루/그린 계열
- 모서리는 과하게 둥글지 않게 유지
- 그림자는 얕게

## Layout Rules

- 검색창이 첫 CTA다
- 홈 첫 화면에서 검색, 카테고리, 대표 카드, 신뢰 기준이 모두 읽혀야 한다
- 시세는 차트보다 표/리스트 우선
- 상품 카드에는 이미지보다 정보 위계가 먼저 보여야 한다

## Content Rules

- 카피는 짧고 직접적이어야 한다
- “왜 믿을 수 있는가”를 홈에서 말해야 한다
- 입문 사용자도 바로 행동을 고를 수 있어야 한다

## Image Rules

- 포켓몬 이미지는 공식 사이트 출처만 사용
- 비포켓몬에 적절한 공식 이미지가 없으면 텍스트형 플레이스홀더를 사용
- 깨진 느낌의 임시 비주얼 금지

## Component Rules

- Search Dock: 검색창 + 추천 검색 + 카테고리
- Hero Spotlight: 대표 카드 1장 + 가격/신뢰 정보
- Quick Paths: 행동 중심 4개 카드
- Market Table: 행 기반 시세 요약
- Trust Strip: 안전결제, 검수, 판매자 신뢰, 최근 거래 기준
- Discovery Shelf: 이유가 있는 큐레이션

## Responsive Rules

- 모바일에서 검색창이 가장 먼저 보인다
- 카테고리와 추천 검색은 2줄까지 허용
- 히어로는 모바일에서 단일 컬럼으로 접힌다

## Anti-Patterns

- 보라색 중심 팔레트
- 과한 그라데이션
- 팬페이지처럼 보이는 연출
- 장식적인 3D/글래스 패널
- 거래 정보보다 카피가 더 큰 화면
