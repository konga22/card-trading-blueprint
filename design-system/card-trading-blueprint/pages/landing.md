# Landing Page Override

이 문서는 `MASTER.md` 위에 홈 랜딩 전용 규칙만 덮어쓴다.

## Landing Goals

- 첫 화면에서 바로 검색하게 만든다
- KREAM처럼 대표 상품과 가격 정보를 강하게 보여준다
- 번개장터처럼 탐색으로 빠르게 이어지게 만든다

## Section Order

1. Top Navigation
2. Search Dock
3. Hero Spotlight
4. Quick Paths
5. Market Table
6. Trust Strip
7. Discovery Shelves
8. Beginner Journey
9. Deep Search Preview
10. Footer

## Landing Rules

- 검색창이 히어로보다 먼저 보여야 한다
- 대표 카드는 1장 크게, 나머지는 보조 정보로만 사용한다
- 추천 검색어와 게임 카테고리는 홈 상단에 둔다
- 홈 카드 섹션은 “왜 보여주는지” 타이틀이 있어야 한다
- 카드 이미지 워터마크/왜곡/잘림처럼 보이면 안 된다
