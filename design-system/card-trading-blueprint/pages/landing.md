# Landing Page Overrides

이 문서는 홈과 공개 랜딩 성격의 페이지에만 적용되는 예외 규칙을 담는다. 공통 기준은 `design-system/card-trading-blueprint/MASTER.md`를 따른다.

## 목표

랜딩 페이지는 서비스 소개보다 행동 선택과 신뢰 형성을 우선한다.

## Section Order

1. Top navigation
2. Search block
3. Hero
4. Quick actions
5. Trust strip
6. Discovery sections
7. Market snapshot
8. Beginner journey
9. Deep search preview
10. Footer

## CTA Rules

- 주 CTA는 검색 제출 또는 핵심 탐색 이동처럼 즉시 실행 가능한 행동이어야 한다.
- 보조 CTA는 시세, 입문, 판매 준비처럼 다음 단계 라우트로 연결한다.
- 한 섹션 안에서 강한 CTA는 하나만 중심을 가져야 한다.

## Density Rules

- 첫 화면에서는 카드 전체 목록보다 선택지를 먼저 보여준다.
- 수치 카드는 2개에서 4개 사이를 권장한다.
- 리스트나 카드 한 개에 가격 관련 수치는 최대 3개 정도만 보여준다.

## Trust Placement

- 검수 가능, 안전 결제, 평판은 별도 소개문보다 카드나 리스트 가까이에 둔다.
- 거래 판단에 필요한 정보는 “자세히 보기” 전에도 읽혀야 한다.

## Responsive Notes

- 모바일에서 검색과 CTA가 첫 화면 안에 들어오도록 우선 배치한다.
- 그리드는 `1 -> 2 -> 4` 열 확장을 기본으로 한다.
- 가로 공간이 부족하면 Trust strip과 chip row는 줄바꿈 또는 가로 스크롤을 허용한다.

## Avoid

- 홈에서 상세 검색 필드를 모두 펼치는 구성
- 홈 히어로 안에서 3개 이상의 행동 버튼을 경쟁시키는 구성
- 과도한 장식 배경으로 텍스트 가독성을 낮추는 구성
