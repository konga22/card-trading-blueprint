# Task Recipes

Use these prompt shapes to activate the skill consistently in this repository.

## New UI Or Section

`Use $card-trading-superpowers to design and implement a new [section] for the home page. Start from AGENT.md, docs/design-reference.md, and docs/home-wireframe.md. Keep the layout 375px-first and split the UI into small reusable components.`

## Feature Work

`Use $card-trading-superpowers to add [feature] in this repo. Make a file-level plan first, keep state in the smallest sensible place, and update tests before implementation code when behavior changes.`

## Search Or Filter Behavior

`Use $card-trading-superpowers to add or change [search/filter behavior]. Write the failing test first, keep URL-backed state when appropriate, and limit changes to the smallest useful surface.`

## Bug Fix

`Use $card-trading-superpowers to debug why [symptom] happens. Reproduce it first, explain the root cause, then fix it and run the relevant verification commands.`

## Code Review Feedback

`Use $card-trading-superpowers to address this review feedback: [paste comments]. Validate each item against the current codebase before changing anything.`

## Pre-Ship Check

`Use $card-trading-superpowers to run a pre-ship check for [feature or page]. Tell me which verification commands passed, failed, or were skipped, and do not claim success without fresh output.`

## Planning Only

`Use $card-trading-superpowers to turn [idea or approved spec] into a repo-specific implementation plan before we edit code.`
