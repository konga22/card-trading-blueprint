# Home Wireframe

## 목적

홈은 모든 정보를 한 번에 다 보여주는 곳이 아니다.  
사용자가 지금 바로 할 수 있는 행동을 빠르게 고르게 하고, 신뢰를 확보한 뒤 검색 또는 거래 화면으로 이동시키는 것이 목적이다.

## 홈의 역할

- 처음 온 사용자를 안심시킨다.
- 검색을 가장 빠른 첫 행동으로 만든다.
- 입문자와 숙련자를 같은 홈에서 분기시킨다.
- 카드 거래에 필요한 최소한의 신뢰 정보는 홈에서 먼저 보여준다.

## 섹션 순서

### 1. Top Navigation

필수 요소:

- 로고
- 검색 진입
- 시세/탐색 이동
- 판매 시작
- 로그인 또는 계정 진입

규칙:

- 링크 수는 적게 유지한다.
- “판매 시작”은 눈에 띄되 과장되면 안 된다.

### 2. Search Dock

역할:

- 홈의 진짜 메인 CTA

필수 요소:

- 큰 검색 입력창
- 빠른 추천 검색어
- 상세 검색 이동
- 최근 많이 찾는 게임 탭

규칙:

- 검색창은 히어로보다 먼저 읽혀야 한다.
- 문구는 짧게, 기능은 분명하게 둔다.

### 3. Hero Split

왼쪽:

- 짧은 제목
- 한 줄 설명
- 검색 보조 CTA 또는 판매 CTA

오른쪽:

- 포켓몬 공식 이미지 또는 공식 카드 비주얼

규칙:

- 큰 감성 카피 금지
- 일러스트는 장식이 아니라 서비스 성격을 보여주는 수준까지만 사용
- 포켓몬 비주얼은 공식 소스만 사용

### 4. Game Tabs

항목 예시:

- 전체
- 포켓몬
- 유희왕
- 원피스
- MTG

규칙:

- 홈에서는 게임 선택을 빠르게 시작하게 한다.
- 게임 선택만으로 바로 검색 결과나 큐레이션으로 이어지게 한다.

### 5. Quick Paths

카드 4개 권장:

1. 입문자 가이드
2. 급상승 카드 보기
3. 안전거래 위주 보기
4. 판매 시작하기

규칙:

- 아이콘보다 제목과 설명이 먼저 읽혀야 한다.
- 이 영역은 “무엇을 눌러야 할지 모를 때”를 해결해야 한다.

### 6. Trust Strip

내용:

- 안전결제
- 검수/인증
- 최근 거래 기준
- 판매자 신뢰 신호

규칙:

- 추상적인 슬로건 대신 구체적인 거래 언어를 쓴다.
- 안전 설명은 첫 화면에 있어야 한다.

### 7. Market Snapshot

역할:

- 지금 시장이 어떻게 움직이는지 한눈에 보여준다.

형식:

- 표형 리스트 또는 짧은 row 카드

표시 정보:

- 카드명
- 최근 거래가
- 전주 대비 변화
- 거래 건수 또는 관심도

규칙:

- 차트 남발 금지
- 숫자는 적되 비교는 가능해야 한다.

### 8. Discovery Shelves

권장 묶음:

- 지금 많이 찾는 카드
- 입문 예산으로 시작하기 좋은 카드
- 안전거래 중심 카드
- 최근 거래가 안정적인 카드

규칙:

- 각 섹션에는 분명한 이유가 있어야 한다.
- “추천 카드” 같은 뭉뚱그린 제목은 쓰지 않는다.

### 9. Beginner Journey

3단계 권장:

1. 카드 찾기
2. 가격/상태 비교
3. 안전하게 구매 또는 판매

규칙:

- 이 영역은 장황하면 안 된다.
- 초보자가 거래 흐름을 한 번에 이해하게 해야 한다.

### 10. Deep Search Preview

보여줄 것:

- 카드번호 검색
- 시리즈/세트 필터
- 상태/등급 필터
- 가격 구간

규칙:

- 홈에서는 미리보기만 보여준다.
- 실제 복잡한 조합은 상세 검색 페이지로 넘긴다.

### 11. Seller Entry

보여줄 것:

- 등록 준비물
- 어떤 정보가 필요할지
- 사진, 상태, 가격 가이드

규칙:

- 판매 진입은 겁주면 안 된다.
- “3분 안에 시작” 같은 과한 카피보다 준비 항목을 명확히 보여준다.

### 12. Footer

필수 링크:

- 고객지원
- 안전거래 안내
- 이용약관
- 개인정보 처리방침

## 모바일 우선 규칙

- 검색창과 게임 탭은 첫 화면 안에 들어와야 한다.
- 히어로는 세로로 길어지지 않게 줄인다.
- 트러스트 스트립과 마켓 스냅샷은 가로 스크롤보다 세로 읽기가 우선이다.

## 홈에서 하지 말 것

- 카드 전체 카탈로그를 첫 화면에 쏟아붓기
- 팬사이트처럼 꾸민 대형 배너
- 데이터보다 배경이 더 강한 히어로
- 클릭해야만 안전거래 정보를 볼 수 있게 숨기기
