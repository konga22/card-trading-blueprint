# Home Wireframe

## 목적

홈은 카드 거래 서비스의 시작 화면이다. 사용자가 홈에서 모든 정보를 다 읽는 것이 아니라, 지금 무엇을 해야 하는지 정하고 적절한 다음 화면으로 이동하도록 돕는 것이 목적이다.

## 섹션 순서

### 1. Top Navigation

역할:
- 현재 서비스가 무엇인지 보여준다.
- 검색, 로그인, 보조 라우트로 이동하는 공통 진입점이다.

필수 요소:
- 브랜드명
- 검색 진입
- 로그인 또는 계정 진입
- 판매 시작 진입

### 2. Search Block

역할:
- 홈의 첫 번째 실질 행동 지점
- 카드명, 카드번호, 세트명 검색의 진입점

필수 요소:
- 검색 입력
- 제출 버튼
- 빠른 추천 검색어
- 상세 검색으로 가는 보조 링크

### 3. Hero

역할:
- 서비스가 어떤 문제를 풀어주는지 한 번에 설명
- 탐색과 거래 판단의 기준을 짧게 전달

필수 요소:
- 짧은 배지
- 한 줄 제목
- 짧은 설명
- 주 CTA 1개
- 보조 CTA 1개

### 4. Quick Actions

역할:
- 사용자가 자주 하는 행동을 바로 선택하게 한다.

고정 카드:
- 처음 시작하기
- 인기 카드 보기
- 시세 확인하기
- 판매 시작하기

### 5. Trust Strip

역할:
- 이 서비스가 가격만 보여주는 곳이 아니라는 점을 바로 전달

핵심 단서:
- 안전 결제
- 검수 가능
- 판매자 평판
- 최근 거래 정보

### 6. Game Filter Chips

역할:
- 사용자가 게임 기준으로 탐색 방향을 좁히게 한다.

기본 항목:
- 전체
- Pokemon
- Yu-Gi-Oh!
- One Piece
- 기타

### 7. Discovery Section: Popular

역할:
- 지금 많이 비교되는 카드 제안

카드 요소:
- 카드명
- 세트/번호
- 현재가
- 최근 거래 또는 가격 변화
- 신뢰 배지

### 8. Discovery Section: Beginner

역할:
- 처음 보기 쉬운 카드 묶음 제안

강조점:
- 입문 적합성
- 비교가 쉬운 카드
- 부담이 적은 시작점

### 9. Discovery Section: Trust-First

역할:
- 검수나 안전 결제가 중요한 카드 묶음 제안

강조점:
- 신뢰 단서 우선
- 가격과 거래 판단을 함께 비교

### 10. Market Snapshot

역할:
- 전체 시세 화면으로 들어가기 전에 핵심 흐름만 요약

표현 방식:
- 복잡한 차트보다 리스트나 로우 중심
- 카드명, 최근 거래, 변동, 거래 수 정도만 요약

### 11. Beginner Journey

역할:
- 입문자가 어디서부터 어떻게 진행하면 되는지 3단계로 안내

권장 단계:
1. 카드 찾기
2. 거래/상태 확인
3. 구매 또는 판매 시작

### 12. Deep Search Preview

역할:
- 숙련 사용자를 위한 상세 탐색 능력을 예고

필수 요소:
- 카드번호 검색
- 세트 기준 탐색
- 언어/상태 필터
- 상세 검색 CTA

### 13. Footer

역할:
- 보조 정보 라우트와 서비스 신뢰 마감

필수 링크:
- 고객 지원
- 안전 거래 안내
- 이용약관
- 개인정보 처리 안내

## 홈에서 하지 않을 일

- 전체 카탈로그를 그대로 펼쳐 보이지 않는다.
- 상세 필터를 한 번에 모두 노출하지 않는다.
- 가격 정보만 크게 강조하고 신뢰 정보를 뒤로 미루지 않는다.
- 보조 라우트 내용을 홈 안에 길게 집어넣지 않는다.
