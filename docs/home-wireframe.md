# Home Wireframe

## 목적

홈의 목적은 모든 것을 설명하는 것이 아니다.  
KREAM처럼 상품과 가격 위계를 먼저 보여주고, 번개장터처럼 바로 검색하거나 좁혀 들어가게 만드는 것이 목적이다.

## 섹션 순서

### 1. Top Navigation

- 브랜드
- 탐색
- 시세
- 안전거래
- 로그인
- 판매 시작

원칙:
- KREAM처럼 단정하고 얇아야 한다.
- 메뉴보다 구조가 먼저 읽혀야 한다.

### 2. Search Dock

- 가장 강한 CTA
- 입력창, 추천 검색어, 게임 카테고리
- 상세 검색 진입

원칙:
- 번개장터처럼 검색이 첫 행동이어야 한다.
- 홈의 첫 화면에서 가장 먼저 읽혀야 한다.

### 3. Hero Spotlight

왼쪽:
- 큰 제목
- 짧은 설명
- CTA 2개
- 핵심 기준 3개

오른쪽:
- 대표 카드 1장
- 가격
- 최근 거래
- 신뢰 배지
- 보조 카드 2장

원칙:
- KREAM 상품 스포트라이트처럼 보여야 한다.
- 동등한 카드 여러 장을 늘어놓는 히어로는 금지한다.

### 4. Quick Paths

- 입문부터 시작
- 시세 먼저 보기
- 상세 검색 열기
- 판매 준비 체크

### 5. Market Table

- 오늘 많이 보는 카드
- 최근 거래가
- 거래 건수
- 상승/하락

원칙:
- 차트보다 표 형식이 우선이다.
- 숫자가 가장 읽기 쉬워야 한다.

### 6. Trust Strip

- 안전결제
- 검수 가능
- 판매자 신뢰
- 최근 거래 기준

원칙:
- 당근처럼 안심 요소를 홈에서 먼저 보여준다.
- 추상적 슬로건보다 실제 거래 기준을 보여준다.

### 7. Discovery Shelves

- 지금 많이 찾는 카드
- 입문용 카드
- 검수/안전결제 중심 카드

원칙:
- 각 묶음에는 “왜 여기 있는지” 이유가 있어야 한다.
- 이미지가 없는 카드도 의도된 정보 카드처럼 보여야 한다.

### 8. Beginner Journey

- 카드 찾기
- 가격과 상태 읽기
- 신뢰 확인 후 거래

### 9. Deep Search Preview

- 카드번호
- 세트
- 언어
- 상태
- 그레이딩

### 10. Footer

- 고객 지원
- 안전거래 안내
- 이용 안내
- 개인정보 처리방침

## 하지 말 것

- 팬페이지 같은 컬러 놀이
- 보라색 AI SaaS 랜딩
- 이미지 카드만 잔뜩 늘어놓는 홈
- 배경 장식이 정보보다 큰 화면
