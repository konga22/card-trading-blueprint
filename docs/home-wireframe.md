# Home Wireframe

## 목적

홈의 목적은 모든 것을 설명하는 것이 아니다.  
사용자가 바로 검색하거나, 시세를 보거나, 판매 준비를 시작하게 만드는 것이 목적이다.

## 섹션 순서

### 1. Top Navigation

- 브랜드
- 탐색
- 시세
- 안전거래
- 로그인
- 판매 시작

원칙:
- KREAM처럼 단정하고 얇아야 한다.
- 당근처럼 “무엇을 할 수 있는지”가 바로 읽혀야 한다.

### 2. Search Dock

- 가장 강한 CTA
- 입력창, 추천 검색어, 게임 카테고리
- 상세 검색 진입

원칙:
- 번개장터처럼 검색이 첫 행동이어야 한다.
- 히어로 문구보다 먼저 보여야 한다.

### 3. Category Rail

- 전체
- 포켓몬
- 유희왕
- 원피스
- 기타

원칙:
- 홈에서도 범위를 빠르게 좁힐 수 있어야 한다.
- 카테고리 선택이 즉시 검색/탐색으로 이어져야 한다.

### 4. Hero Spotlight

왼쪽:
- 큰 제목
- 짧은 설명
- CTA 2개
- 핵심 기준 3개

오른쪽:
- 대표 카드 1장
- 가격
- 최근 거래
- 신뢰 배지

원칙:
- “예쁜 영웅 배너”가 아니라 “대표 상품과 거래 기준”으로 보여야 한다.
- 포켓몬 이미지는 공식 출처만 사용한다.

### 5. Quick Paths

- 입문부터 시작
- 시세 먼저 보기
- 상세 검색 열기
- 판매 준비 체크

원칙:
- 홈에서 고민 없이 첫 행동을 고르게 해야 한다.

### 6. Market Table

- 오늘 많이 보는 카드
- 최근 거래가
- 거래 건수
- 상승/하락

원칙:
- 차트 대신 표 형식에 가깝게 보인다.
- 숫자가 가장 읽기 쉬워야 한다.

### 7. Trust Strip

- 안전결제
- 검수 가능
- 판매자 신뢰
- 최근 거래 기준

원칙:
- 당근처럼 안심 요소를 홈에서 먼저 보여준다.
- 추상적 슬로건보다 실제 거래 기준을 보여준다.

### 8. Discovery Shelves

- 지금 많이 찾는 카드
- 입문용 카드
- 검수/안전결제 중심 카드

원칙:
- 각 묶음에는 “왜 여기 있는지” 이유가 있어야 한다.
- 이미지가 없는 카드도 의도된 정보 카드처럼 보여야 한다.

### 9. Beginner Journey

- 카드 찾기
- 가격과 상태 읽기
- 신뢰 확인 후 거래

### 10. Deep Search Preview

- 카드번호
- 세트
- 언어
- 상태
- 그레이딩

원칙:
- 홈에서는 미리보기만 보여주고, 실제 조합은 상세 검색으로 넘긴다.

### 11. Footer

- 고객 지원
- 안전거래 안내
- 이용 안내
- 개인정보 처리방침

## 하지 말 것

- 이미지 카드만 잔뜩 늘어놓는 홈
- 팬페이지 같은 컬러 놀이
- 보라색 AI SaaS 랜딩
- 배경 장식이 정보보다 큰 화면
