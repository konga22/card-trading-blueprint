# Catalog Taxonomy

이 문서는 카드가 많고 종류가 복잡할 때도 신규 유입과 숙련자를 동시에 잡기 위한 분류 전략이다.

## 1. 원칙

### 원칙 A. 사용자 분류와 시스템 분류를 분리한다
사용자 화면에서 보이는 분류와, 실제 DB의 분류는 다를 수 있다.

### 원칙 B. 처음은 단순하게 시작한다
첫 화면에서는 아래 4개만 강하게 노출한다.
- 게임
- 목적
- 가격대
- 상태/검수

### 원칙 C. 깊은 필터는 뒤로 숨긴다
세트, 카드번호, 언어, 판본, 홀로 여부는 상세 필터로 이동한다.

---

## 2. 사용자용 분류

### 1차
- 전체
- 포켓몬
- 유희왕
- 원피스
- 기타

### 2차
- 입문용
- 컬렉션용
- 플레이용
- 희귀/한정판

### 3차
- 싱글 카드
- 그레이드 카드
- 세트
- 박스/팩

### 4차 (상세)
- 세트
- 카드번호
- 언어
- 레어도
- 에디션
- 홀로/리버스 홀로
- 상태
- 그레이드 회사
- 그레이드 점수

---

## 3. 시스템용 분류(예시)

```text
game
  -> set
    -> cardName
      -> cardNumber
      -> rarity
      -> language
      -> edition
      -> holoType
      -> condition
      -> gradingCompany
      -> gradeScore
```

## 4. 홈 화면에 적용하는 법

### 홈 첫 화면
- 게임 칩
- 의도 기반 섹션
- 가격/신뢰/입문 여부 중심

### 구매 리스트
- 기본 필터 4개만 노출
- 상세 필터 드로어 별도

### 검색 결과
- 카드번호 검색 지원
- 세트 좁히기
- 정렬: 인기 / 최신 / 낮은 가격 / 높은 가격 / 최근 거래

---

## 5. 입문자와 숙련자를 동시에 잡는 방법

### 입문자
- `처음 시작해요`
- `입문 추천`
- `최근 거래가`
- `검수 가능`

### 숙련자
- 카드번호
- 세트
- 언어
- 판본
- 등급
- 판매자 조건

---

## 6. 금지

- 홈에 세트 트리를 전부 펼침
- 상세 필터를 기본 노출
- 처음부터 카드번호/판본 필수 이해 강요

---

## 7. 향후 확장

서비스가 커지면 아래를 추가할 수 있다.

- 위시리스트 자동 분류
- 세트 완성도 추적
- 즐겨찾는 게임/세트 기반 개인화 홈
- 가격 알림
