# Design Reference

## 문서 목적

이 문서는 카드 거래 서비스의 시각 방향을 한 문장으로 정리하고, 어떤 성격의 화면을 만들어야 하는지 기준을 제공한다. 이 버전은 `ui-ux-pro-max`의 로컬 데이터셋을 바탕으로 다시 정리한 결과다.

## 기준으로 삼은 조합

### 제품 성격

- `Marketplace (P2P)`: 검색, 필터, 매물, 판매자 신뢰 단서가 중요하다.
- `Service Landing Page`: 첫 화면에서 핵심 행동을 빠르게 선택하게 해야 한다.
- `B2B Service`: 과장보다 신뢰와 명확성이 우선이다.

### 스타일 조합

- `Swiss Modernism 2.0`: 구조가 분명하고 장식이 적은 레이아웃
- `Accessible & Ethical`: 높은 대비, 큰 터치 영역, 분명한 포커스
- `Trust & Authority`: 보안, 검수, 평판, 거래 단서를 명확히 노출

### 랜딩 패턴 조합

- `Hero + Features + CTA`
- `Funnel (3-Step Conversion)`

## 최종 방향 한 줄 요약

이 프로젝트의 공개 화면은 “검색이 빠르고, 구조가 분명하며, 가격과 신뢰를 같이 판단하게 돕는 거래형 인터페이스”를 목표로 한다.

## 시각 원칙

### 1. 구조가 먼저 보여야 한다

- 섹션 경계가 분명해야 한다.
- 무엇을 할 수 있는지 먼저 보이고, 긴 설명은 뒤로 물린다.
- 홈은 정보 과시보다 행동 선택에 집중한다.

### 2. 신뢰 단서를 가격 옆에 둔다

- 검수 가능 여부
- 안전 결제 여부
- 판매자 평판
- 최근 거래 정보

위 정보는 상세 페이지에만 숨기지 않고 카드나 리스트 수준에서도 읽혀야 한다.

### 3. 검색이 서비스의 중심이다

- 검색 입력은 홈 상단에 가까운 위치에 둔다.
- 카드명 외에 카드번호, 세트, 상태 같은 깊은 탐색으로 이어지는 구조를 제공한다.
- 검색 상태는 라우트와 함께 이해되는 인터페이스여야 한다.

### 4. 차분하지만 건조하지 않다

- 전체 화면은 중립적인 배경과 높은 가독성을 유지한다.
- 강조는 1개의 메인 브랜드 축과 1개의 행동 색으로 제한한다.
- 아이콘과 배지는 의미를 보조하되 화면을 장식용으로 채우지 않는다.

## 레이아웃 원칙

- 모바일 우선으로 설계한다.
- 카드와 리스트를 섞되, 한 화면에서 정보 밀도가 갑자기 튀지 않게 조절한다.
- CTA는 한 섹션에서 하나의 주행동이 우선순위를 가져야 한다.
- 검색, 탐색, 시세, 판매 준비는 각 라우트에서 밀도를 달리한다.

## 인터랙션 원칙

- 애니메이션은 150ms에서 220ms 사이의 짧은 반응만 사용한다.
- 움직임은 클릭 가능한 요소와 상태 변화에만 제한한다.
- `prefers-reduced-motion`을 고려한다.
- hover는 레이아웃을 흔들지 않는 색상, 테두리, 그림자 변화 위주로 설계한다.

## 안티패턴

- 홈에서 전체 카탈로그를 한 번에 보여주는 구성
- 가격만 크고 신뢰 단서가 따로 숨어 있는 카드
- 브랜드 색을 여러 개 섞어 채도 경쟁을 만드는 구성
- 사용자가 현재 어디에 있는지 알 수 없는 네비게이션
- 근거 없는 통계, 과한 차트, 과장된 마케팅 카피
- 시각적으로만 구분되고 텍스트나 아이콘 의미가 없는 상태 표기
