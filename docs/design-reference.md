# Design Reference

## 문서 목적

이 문서는 카드 거래 서비스의 시각 기준을 추상적인 취향이 아니라 실제 서비스 레퍼런스에 맞춰 정의한다.  
기준 레퍼런스는 번개장터, KREAM, 당근, 포켓몬 공식 사이트다.

## 레퍼런스 소스

### 공식 링크

- 번개장터 모바일: `https://m.bunjang.co.kr/`
- 번개장터 리포트: `https://static.bunjang.co.kr/press/Bunjang_ESG_report_20230227.pdf`
- KREAM 서비스: `https://kream.co.kr/`
- KREAM 회사 소개: `https://www.kreamcorp.com/`
- 당근 서비스 소개: `https://www.daangn.com/kr/`
- 당근 브랜드/보도자료: `https://about.daangn.com/`
- 포켓몬 공식 사이트: `https://pokemonkorea.co.kr/`
- 포켓몬 카드 공식 사이트: `https://pokemoncard.co.kr/main`

### 1. 번개장터

- 참고 방향: 검색 중심 탐색, 브랜드/카테고리 진입, 거래 정보 밀도, 안전결제 노출
- 참고 포인트:
  - 사용자는 품목명보다 브랜드나 구체 키워드로 탐색하는 경우가 많다.
  - 팔로우, 상태, 배송, 결제 혜택 같은 정보가 상품 근처에 붙어 있다.
  - 거래 안전 정보가 상세 페이지 뒤가 아니라 구매 결정 지점 가까이에 있다.
- 해석:
  - 홈과 검색은 “예쁜 쇼윈도”보다 “바로 찾고 비교하는 장터”처럼 보여야 한다.
  - 카드 한 장 안에 가격, 상태, 신뢰 신호를 짧고 빠르게 읽을 수 있어야 한다.

### 2. KREAM

- 참고 방향: 프리미엄 리셀 톤, 정갈한 정보 위계, 과장 없는 화면 밀도
- 참고 포인트:
  - 트렌드 플레이그라운드라는 정체성을 유지하면서도 거래 화면은 건조하고 정리돼 있다.
  - 구매/판매 입찰과 검수 기준을 강한 정보 위계로 묶는다.
  - 화려한 색보다 타이포와 간격으로 분위기를 만든다.
- 해석:
  - 카드 거래 서비스도 감성보다 구조가 먼저 보여야 한다.
  - 첫 화면부터 “검색, 시세, 검증, 판매 진입”이 또렷해야 한다.

### 3. 당근

- 참고 방향: 따뜻한 로컬 신뢰감, 근처 거래 문맥, 홈과 검색의 역할 분리
- 참고 포인트:
  - 동네 기반 정체성을 홈에서 분명히 보여준다.
  - 안전 설명과 보호 장치를 서비스 문맥 안에서 자연스럽게 드러낸다.
  - 넓은 탐색은 검색에서, 기본 피드는 가까운 문맥에서 시작한다.
- 해석:
  - 홈은 입문자와 일반 사용자를 안심시키는 화면이어야 한다.
  - 깊은 카드 탐색은 검색으로 넘기되, 홈에서는 빠른 진입과 안전한 첫 행동을 돕는다.

### 4. 포켓몬 공식 사이트

- 참고 방향: 캐릭터와 카드 이미지는 공식 소스만 사용
- 자산 원칙:
  - 포켓몬 캐릭터/도감 이미지: `pokemonkorea.co.kr/pokedex`
  - 포켓몬 카드 이미지: `pokemoncard.co.kr`의 카드검색, 제품정보, 카드 상세
- 금지:
  - 팬아트
  - 위키 크롤링 이미지
  - 비공식 PNG 모음
  - 해상도 불명 외부 썸네일

## 최종 디자인 성격

이 프로젝트는 “귀여운 팬페이지”가 아니라 “실제 카드 거래 서비스”처럼 보여야 한다.

- 기본 톤: 한국형 리셀 마켓
- 핵심 느낌: 정갈함, 신뢰감, 빠른 탐색, 적당한 온기
- 배제할 느낌: AI 랜딩페이지, 과한 그라데이션, 장식용 3D, 의미 없는 유리질감

## 조합 원칙

### 번개장터에서 가져올 것

- 검색이 먼저 오는 구조
- 거래 정보의 촘촘한 배치
- 상품 가까이 붙는 상태/배송/결제 힌트

### KREAM에서 가져올 것

- 흑백에 가까운 정리된 기본 화면
- 가격과 정책을 또렷하게 읽게 하는 타이포 위계
- 과장 없는 프리미엄 톤

### 당근에서 가져올 것

- 초보자도 부담 없는 친절한 톤
- 안전성과 신뢰를 홈에서 먼저 보여주는 방식
- “근처에서 시작하고, 필요하면 더 넓게 찾는다”는 흐름

### 포켓몬 공식에서 가져올 것

- 세계관과 캐릭터의 정확성
- 카드 이미지의 정본성
- 비주얼보다 출처 신뢰를 우선하는 자산 운영

## 화면 언어

### 전체 인상

- 흰색과 웜 그레이를 바탕으로 한다.
- 블랙 계열 텍스트로 정보 위계를 세운다.
- 포인트 컬러는 적게 쓰고, 상태와 행동 의미가 분명할 때만 쓴다.

### 홈 화면

- 검색창이 가장 먼저 눈에 들어와야 한다.
- 히어로는 큰 감성 문구보다 “무엇을 할 수 있는지”를 짧게 설명해야 한다.
- 홈에서 보여주는 카드 묶음은 “입문”, “급상승”, “안전거래”, “최근 관심”처럼 판단 가능한 주제로 나뉘어야 한다.

### 검색/리스트

- 카드 이미지는 눈길을 끄는 요소가 아니라 판별을 돕는 요소다.
- 가격, 등급, 번호, 상태, 거래 방식이 같은 밀도 안에 정리돼야 한다.
- 필터는 눈에 띄되 복잡하게 보이면 안 된다.

## 절대 하지 말 것

- 보라색 위주의 스타트업형 그라데이션
- 첫 화면 전체를 덮는 거대한 추상 배경
- 포켓몬을 스티커처럼 여기저기 흩뿌리는 구성
- 정보보다 장식이 더 큰 카드
- 실제 거래 서비스인데 팬 굿즈 블로그처럼 보이는 카피
