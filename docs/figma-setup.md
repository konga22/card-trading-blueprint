## 스타일 가이드

- 컬러와 타이포는 `docs/design-tokens.md`를 따른다
- 검색창과 상품 카드의 정보 위계를 먼저 만든다
- 장식보다 데이터 가독성을 우선한다

## 체크리스트

- 검색창이 첫 CTA로 보이는가
- 가격과 최근 거래가 충분히 크게 보이는가
- 신뢰 정보가 카드 근처에서 읽히는가
- 포켓몬 이미지는 공식 출처만 쓰고 있는가
- 모바일에서 정보 순서가 무너지지 않는가
