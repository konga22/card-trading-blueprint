# Home Components

`src/components/home/` stores page-level and section-level UI used by the public marketing routes.

## Use this folder for

- Home page composition
- Discovery, market, search hub, beginner, and sell-start pages
- Section components that are not meant to be reused across the whole app

## Do not use this folder for

- Generic buttons, badges, or cards
- Pure domain logic
- Global layout primitives

Shared UI belongs in `src/components/shared/`.
